## 📚 Project Description
- **A brief description of the project:** AeroSonar is a purely passive, acoustic-based early warning and azimuth estimation prototype designed to detect hostile Unmanned Aerial Vehicles (UAVs) in real-time. It isolates the unmaskable acoustic noise generated by drone rotors to bridge the gap between binary acoustic identification and continuous spatial tracking.
- **A list of the main features and functionalities:** Real-Time Presence Verification via CNN, Continuous Spatial Tracking (360-degree DoA), Noise Gating & Interference Rejection, and Bounded Edge Computing via a strict 41 ms real-time processing window.
- **A list of the main components of the project:** An 8-channel Uniform Circular Array (UCA) using omnidirectional electret microphones, a Presence Verification Node (single digital microphone to host PC), and an Edge Compute Node (STM32H753ZI microcontroller).
- **A list of the main technologies used in the project:** Deep Learning Classification (PyTorch CNN processing STFT Mel-Spectrograms), Embedded DSP (SRP-PHAT and GCC algorithms in C/C++), and Hardware-Level Autonomous Acquisition (DMA and circular double-buffering via STM32 HAL).
